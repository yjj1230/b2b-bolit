## 本轮修复的冷启动缺口（A 轨基础 compose）
1. `temporal` 的 `DYNAMIC_CONFIG_FILE_PATH=development-sql.yaml` 在
   `auto-setup:1.24.2` 镜像内不存在 → `docker.yaml`；并补健康检查（容器 IP）。
2. `spicedb` 镜像 v1.39.1 无 `healthcheck` 子命令且无 shell → Dockerfile
   `spicedb` 目标内置 gRPC 探针；并补 `--http-enabled`。
3. `spicedb-schema` 原命令 `spicedb validate/relationship` 在 v1.39 CLI 不存在，
   且 `|| true` 吞掉失败 → 冷启动实际不会写 schema。改为 Dockerfile target
   seedrel + `-schema /schema.zed`（写 schema + 关系基线，幂等）。
4. api/worker 只依赖 `temporal: service_started`，Temporal 服务启动 8 秒内
   api/worker 抢先拨号失败退出 → temporal 补 healthcheck，api/worker 改为
   `service_healthy`；api/worker 同时补 `spicedb-schema completed` 依赖。
5. `docker-compose.override.yml`（服务器）同步：api depends_on 增加
   spicedb-schema completed 与 temporal healthy。
