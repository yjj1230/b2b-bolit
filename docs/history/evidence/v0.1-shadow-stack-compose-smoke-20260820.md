## 本轮修复的冷启动缺口（8 处）
1. `shadow-ingest/feed` 把配置 bind 到 `/etc/shadow/*` —— alpine 基础镜像已有
   `/etc/shadow` 口令文件，`runc` 拒绝创建挂载点。改为 `/etc/b2b/{ingest,feed}.json`。
2. Temporal `DYNAMIC_CONFIG_FILE_PATH` 指向镜像内不存在的
   `config/dynamicconfig/development-sql.yaml` —— `auto-setup:1.24.2` 只有
   `docker.yaml`，改为 `config/dynamicconfig/docker.yaml`。
3. Temporal 健康检查连 `127.0.0.1:7233` —— `auto-setup` 只监听容器 IP，
   改为 `tctl --address $(hostname -i):7233`。
4. SpiceDB v1.39.1 无 `healthcheck` 子命令且官方镜像无 shell —— 新增
   `cmd/spicedb-healthcheck`（grpc.health.v1 + preshared key）和 Dockerfile
   `spicedb` / `shadow-spicedb` 目标，compose 探针改用内置二进制。
5. `shadow-temporal-init` 的 YAML 折叠多行在 `||` 前残留换行，`sh -c` 报
   `syntax error: unexpected "||"` —— 改为单行命令。
6. shadow-api 白名单收紧后 `/healthz` 返回 401（默认 principal `u-op` 不在
   白名单）—— 探针改为取 `B2B_SHADOW_PRINCIPALS` 首项（`%%:*`）作为
   `X-User-Id`。
7. `spicedb serve` 只给了 `--http-addr` 未给 `--http-enabled`，8443 网关不
   监听 —— 补齐 `--http-enabled`。
8. `shadow-seedrel` 未传 `-schema`：v1.39 CLI 没有 schema/relationship
   子命令，首次启动所有关系 touch 都因 object definition 不存在而 WARN
   （影子库实际无 schema）—— 挂载 `schema.zed` 并传 `-schema`，重跑后全部 ok。
