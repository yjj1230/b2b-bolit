3.2 风险与边界

  • 覆盖率 87.3% 与目标 ≥95-98% 的差距（约 320 语句）全部位于防御性错误分支（pgx 扫描错误、SQL 失败返回、物理不可达分支）——docs/03 §3 与 docs/06 §2 有诚实声明。
  • Timer 驱动路径（补回单分流②、精确催办时间点）依赖虚拟时间，E2E 按「自动触发」语义覆盖；精确语义在 internal/workflows TestSuite（L2-07/11/13）。
  • 多套件共享测试 PG（b2b_pilot_test）：并行执行会 schema 冲突（本会话已验证），须按 Makefile 顺序目标串行运行。
