3.2 问题二：测试覆盖率是否 ≥95% — ❌ 未达成（实测 87.8%）

  1. 实测：全仓 87.8%（门禁 85% + domain 100% 硬门禁 PASS）；距离 95% 目标差 7.2pp；距离文档目标 98% 差 10.2pp。
  2. 缺口分解：repo 80.9%（-14.1pp，最大缺口：pgx scan error、每句 SQL 失败返回）、workflows 86.3%、api 91.5%、wecom 94.5%、authz 95.7%。全部为防御性错误分支，部分物理不可达（如负库存分支被 CHECK(qty>=0) 阻断——是「防线生效」而非「测试缺失」）；正确性核心 domain 100%。
  3. 诚实声明：不以上轮「96.0% 假绿」为基线——门禁已修复为完整 8 包 profile + 数值比较 + 缺包即 FAIL；87.8% 为真值。
