操作 3.1

待办 Tab 代办授权

管理员创建代办授权：代办人、权限范围、有效期；到期后代办点击卡片 → 403「任务已失效或您无操作权限」。

到期后代办不持有残留权限；不会因代办过期造成越权推进（07 §4.5.8）。
