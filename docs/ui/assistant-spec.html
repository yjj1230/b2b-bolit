Role Spec · 销售助理 代销售下单 · 归属锁定

销售助理· 角色规约页

销售助理是代下单角色：可为指定销售创建订单，但不能代替销售确认智能下单、审批或对客决策。本页 2 个 Block 覆盖销售助理在企微的全部场景：工作台代下单（XSZL1）与客户群入口代下单（XSZL2）。UI 操作图同时呈现 PC 端四栏与移动端手机屏幕，严格采用产品稿 spec/ui/wecom-sidebar 的企微设计语言。每个 Block = 用例图 + 流程图 + UI 操作图。

操作 1.1

工作台 → 下单 Tab → 选择归属销售

销售助理从手机/PC 工作台打开订单助手，切到「下单」Tab；表单顶部出现「下单归属销售」选择器，决定后续可选客户范围。

工作台没有群上下文，系统不能自动确定客户；必须先选归属销售，再人工选客（A7 多方分担）。

操作 2.1

客户群 → 订单助手 → 下单 Tab（归属锁定）

销售助理在「广西天华 · 供应协同群」点击「订单助手」，打开后进入「下单」Tab；群上下文直接确定客户，归属销售自动带出并锁定（readonly 不可改）。

每个客户归属的销售是明确的（B6/C2）；群入口与工作台入口的本质区别就是无需手动选择归属销售。

操作 2.2

提交成功 → 后续审批链

销售助理核对无误后点「提交订单」→ 已代张销售提交正式订单，展示订单号与完整后续流程（主管审价 → C 级董事长终审 → 商务库存/交期确认 → 仓管发货 → 回单 → 财务开票）。

提交后订单进入正常审批链；销售助理不承担审批职责，可「去待办跟踪」查看状态。
