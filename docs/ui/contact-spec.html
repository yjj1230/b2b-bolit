客户联系人· 角色规约页

操作 1.1

「订单」Tab：我的物流（剥金额）

客户联系人「订单」Tab 展示本客户发货单：发货进度、物流单号、预计送达——金额行不渲染、无内部备注（产品稿 order-item 去金额变体）。

投影规则：客户联系人拥有 shipment.view（物流视图），但不获得价格/内部备注（CQ-03）。

操作 2.1

待办 Tab 签收凭证登记反馈

上传成功后待办 Tab 出现「签收已登记」审批条（动态）；凭证只追加，历史版本可回放；若开通出站则通知销售。

重复提交同版本 → toast「该凭证已登记」（409 幂等）。
