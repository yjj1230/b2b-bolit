财务· 角色规约页

confirm_payment = reviewer + tenant->accounting + tenant->admin 是财务专属授权——到账确认面向租户全量订单（需价格/账期核算）。UI 操作图采用产品稿设计语言，Tab 裁剪为「待办 / 订单」。本页 3 个 Block。

操作 3.1

回单异常详情（风险提示）

点击回单异常审批条进入详情：发货日期、回单状态、超期天数（橙色 tag「已超期 3 天」）；「处理异常」进入例外审核。

回单异常为工作流 assignee 判定，非财务专属 permission（07 §4.5.4）。
