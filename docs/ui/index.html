角色规约页
用例图 · 流程图 · UI 操作图

每个角色一个独立页面，每页分为 N 个 Block；每个 Block 由三要素组成：① 用例图（参与者与系统边界）→ ② 流程图（操作步骤流转）→ ③ UI 操作图（每个操作给一段说明 + 一个页面）。UI 操作图同时呈现两种企微真实形态：PC 端四栏（① 标准按钮列 → ② 联系人 → ③ 对话框 → ④ 侧边栏应用，最右栏绿色标注"我们的应用"）+ 移动端手机屏幕（聊天窗口 + 工具栏「订单助手」入口 + 全屏 H5）。设计语言强参考产品稿 spec/ui/wecom-sidebar（PC 暗色 #202124 / 移动端浅色 #F4F5F7 + #07C160 企微绿，3 Tab「待办·订单·下单」按角色裁剪）。数据为虚拟演示：企业=长安仁恒，客户=广西天华，商品=膨润土 AB-3。业务语义以 07 与 07a 为事实源。
