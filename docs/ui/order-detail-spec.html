查看订单详情· 通用页面规约

订单详情是全部角色的通用页面：从订单列表、待办审批条、AI 问单直达、或工作台均可进入。页面必须展示四节点履约时间线（已开单 → 已备货 → 已发货 → 已开票），并按角色做字段投影（仓管/客户联系人剥价，销售/商务/主管/董事长看全字段）。本页定义两种形态：全字段详情与剥价详情；UI 操作图同时呈现 PC 端四栏与移动端手机屏幕。

操作 2.1

仓管发货任务：金额不可见

仓管打开发货任务详情：只展示产品、数量、发货仓、收货地址、交期；金额字段整体不渲染，不留空列，也不显示「—」。底部「确认接受」/「拒绝并说明」。

剥价是 CQ-03 强制规则：仓管视图不出现价格/金额，字段级投影由后端完成。
