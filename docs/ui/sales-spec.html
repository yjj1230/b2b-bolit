归属销售· 角色规约页

销售是唯一能在 S2 确认自动下单的角色（归属校验 SpiceDB + 本地 StaticChecker）。本页 5 个 Block 覆盖销售在企微的全部业务操作。UI 操作图严格采用产品稿 spec/ui/wecom-sidebar 的企微移动端设计语言：#F4F5F7 背景 / #07C160 企微绿 / #1F2329 文字 / 卡片圆角 6px / 3 Tab 结构（待办·订单·下单）。每个 Block = 用例图 + 流程图 + UI 操作图。
