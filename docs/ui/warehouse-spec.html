Role Spec · 仓管 本仓发货 · 剥价视图

仓管· 角色规约页

仓管仅见本仓分配的发货单（shipment#warehouse_operator），经 warehouse.staff 获得 order.view 但不获得价格字段——BFF 投影剥价（CQ-03）。UI 操作图采用产品稿设计语言，Tab 裁剪为「待办 / 订单」。本页 3 个 Block。

操作 1.1

「订单」Tab：本仓发货单（剥价）

仓管「订单」Tab 展示本仓发货单，订单卡金额行不渲染（剥价视图，产品稿 order-item 去掉金额）；显示单号/状态/产品/数量/仓库。

投影规则：仓管不获价格字段（CQ-03）——UI 上金额列整体不渲染，不留占位。

待办 Tab 回单凭证登记反馈
