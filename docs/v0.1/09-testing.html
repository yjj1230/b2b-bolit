4 · 覆盖率门禁

包门禁说明
domain（FSM/值对象/守恒/幂等）100% 硬门禁图谱正确性的唯一事实源
authz / api / wecom≥98%（目标）余量为防御性错误分支
repo / workflows≥98%（目标）余量为 pgx scan error 与 SQL 失败返回
integration100%含 DemoPolicy 虚拟时长契约
全仓合计≥85% 实测门禁（目标 ≥98%）当前 87.8%（2026-08-07 基线）；0.1 新增 N-01..N-10 用例后回测
门禁实现：go test -count=1 -tags integration -coverprofile=coverage.out ./internal/... + awk 数值比较；domain 100% 硬门禁 + 全仓 ≥85%。（沿用 03-testing 诚实声明：错误注入 ≠ 真实故障形态；覆盖率 100% ≠ 故障注入等价性 100%。）
