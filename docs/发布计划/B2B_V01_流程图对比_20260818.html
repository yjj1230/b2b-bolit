图三：目标模型（v0.1 销售助手下单 + 飞书流续跑）

flowchart LR
    subgraph V01["v0.1（Go + PG + 企微，Docker）——全部新增开发量在此"]

        BR["下单桥接模块（v0.1 新增）<br/>①代理飞书 OAuth 换 create-order token（2h 缓存）<br/>②调旧系统既有创建接口（幂等）"]
        PG[("PG：本系统订单<br/>flow_id/instance_id/状态摘要")]

    end
    subgraph OLD["三方审批系统（仅一处针对性小改：自动确认+profile 注入；其余零改动）"]

        API["POST /external-orders/create<br/>（既有：创建订单+审批实例+合同+通知+台账）"]

    end
