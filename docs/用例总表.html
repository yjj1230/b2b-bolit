① 通用约定（demo 全角色一致）

以下规则在 demo 中已统一落地，所有角色 / 场景均遵守。

📱终端形态

全部角色默认手机端（单手机：群聊 ⇄ 订单助手应用页同屏切换），演示页支持 PC / 移动切换；商务 / 财务额外标记 PC 必需。

⛓️订单状态四节点

所有订单状态统一用直线连接的四个节点表述：已开单 → 已备货 → 已发货 → 已开票，当前节点高亮（订单列表紧凑版 + 详情完整版）。

🤖凭证机器人

所有凭证上传优先转发「凭证机器人」自动识别登记；各角色保留「上传凭证」入口 / 订单详情上传为备选，两路等价。

📝审批备注

所有审批动作（通过 / 驳回 / 放行）均支持填写备注，随审批记录可追溯。

🖼️客户截图

发到群里的订单 / 物流图片为普通图片（无「订单助手」角标、无「AI 生成」字样），像销售自己贴的图。

🧭群内 / 群外

群内=围绕群内该客户服务（群侧边栏）；群外=订单助手 / 工作台独立入口，无群上下文全量。
