# 第一次发布前现场调研：证据索引与回填说明

## 本次范围

- 发布阶段：第一次发布前。
- 现场截图包：按用户要求暂缓，不影响其他交付物生成；涉及后台界面的 L2 证据仍保留在《证据缺口清单》中。

## 回填方式

1. 将取证台账摘要回填《分期部署数据流分析》附录 A。
2. 将生产基线回填数据库读写梳理和风险表，后续发布前后沿用相同统计口径。
3. 将异常清单转成发布阻塞项或方案修订项。
4. 将证据缺口标记为“待现场复核”，补齐后更新证据等级和 Go/No-Go 结论；R1-02 已完成 L1 核验，不再依赖用户确认。
5. 当前 pgAPI 架构以修正后的三表为准：customers、products、purchase-contracts；旧五表口径不再使用。
