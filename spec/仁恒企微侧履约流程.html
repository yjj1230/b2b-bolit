一、标签运营

1进入 客户联系 → 客户群 → 群标签。
2点「新建标签组」，建以下标签组与标签：
标签组标签内容
行业/品类涂料、造纸、日化、环保、石油、医药、农业、饲料…（按实际客户补全）
客户分级KA战略、A重点、B常规、新客
履约阶段待发货、已发货在途、已签收待验收、已验收待开票、已完成
异常状态售后中
客户成员角色采购、收货人、技术、决策人
3建群后，在 群设置 → 群标签，按《群标签配置表》手动打静态 + 成员标签；履约阶段后续每次沟通更新。

二、配入群欢迎语

1进入 客户联系 → 配置 → 欢迎语（入群欢迎语）。

三、开会话存档（合规留痕）

1进入 管理工具 → 会话内容存档。
2按公司合规要求开通并配置可见范围（需企业认证 + 员工告知）。
3存档是后续 NLU 训练语料与异常追溯的数据底座；开通后告知陈虹励 / 销售。

附：企微运营-拉群SOP子文档 · 最近修改：8月5日 16:00 · 对应「壹、企微拉群」环节

一、群命名规则

仁恒服务群-客户公司名-行业

例：仁恒服务群-菜花科技-涂料

二、拉群SOP · 方案一：陈虹励群主

1陈虹励用企微发起群聊，一次性拉入：
  • 财务（企微）
  • 销售（企微）
  • 陈虹励自己的个微
前 5 个群左右三方均无需同意，建群时直接进。因含陈虹励个微这一外部联系人，群从创建起就是外部群。但 5 个后仍需每个进群人员点击邀请卡片同意，方可进群。
2陈虹励发任意一句话（1）—— 群正式生效、对客户可见。
3销售拉外部客户：销售（成员）把客户（外部联系人）拉进该群。
客户无需同意。
4改名：改为 仁恒服务群-客户名-行业（非群主亦可改，建议陈虹励统一改）。
5发完整欢迎语 + 商务/财务/销售亮身份。
6履约服务启动。

二、拉群SOP · 方案二：「创建新外部群」触发流 ★推荐

1陈虹励用企微发起群聊，一次性拉入：
  • 财务（企微）
  • 销售（企微）
纯内部群，用于前期沟通 + 触发外部群。三方均无需同意，建群时直接进。发送任意一条消息后，销售财务对该群可见。
2销售在预备群内拉客户：销售点右上角「…」→「添加群成员」→ 搜索并选中外部客户（如"赤鲸 @微信"）。
3弹出提示框："需创建一个新的外部群才能支持添加外部联系人加入到群聊" —— 下方有「取消」「创建」。
4销售点「创建」：系统自动生成全新外部群（非原群升级）。
  • 销售自动成为新群群主；客户自动进群，无需同意。
  • 同时给原预备群成员（陈虹励、财务）发邀约卡片。
5陈虹励 / 财务点卡片进入新群：各自点企微消息里的卡片即可进群（无需额外审批）。
6改名：改为 仁恒服务群-客户公司名-行业（非群主亦可改，建议陈虹励统一改或销售按模板改）。
7发完整欢迎语 + 商务/财务/销售亮身份。
8履约服务启动（发货通知 / 文件自动发 / 进度同步…）。
9返回「订单预备群」：对每个新客户重复步骤 1~7，系统为每个客户生成一个独立的全新外部群。
