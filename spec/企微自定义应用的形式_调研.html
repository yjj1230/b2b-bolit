P1 · 企微应用形态总览 —— 能开发什么样的企微应用

纷享销客的企微整合文档揭示了企微自定义应用的完整形态谱系。核心结论：企微应用分「自建应用」与「代开发自建应用」两种形态，前者由企业自己创建、页面用 URL 或应用主页承载；后者由服务商（纷享销客）代开发，企业扫码安装、授权后使用，可解锁更深的平台能力（如会话存档的数据与智能专区）。

1.1 两种应用形态对照

维度自建应用代开发自建应用
创建方式企业微信管理后台 → 应用管理 → 自建，企业自己维护服务商（纷享）提供二维码，企微管理员扫码安装；安装后显示「开发中」，由服务商代为上线
典型实例纷享销客CRM 第三方应用（应用市场添加）；本项目的订单助手自建应用纷享销客代开发应用（CRM 主体）、纷享营销助手代开发应用（营销主体）
页面承载应用主页（应用配置的默认页）或 自定义页面 URL（聊天工具栏挂任意 H5）应用主页 + 专属功能（如会话存档需启用数据与智能专区）
可见范围按部门/人员设置；人数按购买计费，超出需增购按部门/人员/成员标签设置；官方建议用成员标签（如「CRM使用人」）统一管理
适用场景企业自有业务系统对接（如订单履约系统）；页面即 H5 URL，零平台开发成本需要深度平台能力（会话存档、小程序身份互通、公众号打通）或需服务商持续代维护

P3 · 配置上线全流程 —— 怎么把应用配上去

以下为纷享销客「企业微信关联配置流程」的完整 6 步操作（来源），是本项目配置企微集成的直接操作蓝本。其中步骤 2、3、5 是订单履约系统整合必需的最小路径（自建/添加应用 → 授权 → 配置侧边栏 URL）。

步骤 1 · 接入营销渠道（可选）
仅需营销功能（活动营销/微页面/公众号/小程序）时执行；绑定微信公众号/小程序到纷享（营销通）。订单履约场景可跳过。证据：/86b2/9bdb/ef01/7044/4b2a 步骤1
步骤 2 · 添加纷享销客 CRM 应用（自建应用形态）
企微后台 → 应用管理 → 第三方栏 → 添加第三方应用 → 搜索「纷享销客」→ 添加 → 设置可见范围（部门/人员）。证据：/86b2/9bdb/ef01/7044/4b2a 步骤2
步骤 3 · 授权代开发应用（服务商代开发形态）
企微管理员扫码安装 → 显示「开发中」→ 通知服务商上线 → 管理员确认授权（必须授权，否则部分数据无法同步）→ 设置可见范围（建议成员标签）。证据：/86b2/9bdb/ef01/7044/4b2a 步骤3
步骤 4 · 授权营销助手代开发应用（可选）
营销场景专用：扫码安装「纷享营销助手」+「纷享营销助手-小程序」两个应用，同样需商务上线 + 管理员授权。证据：/86b2/9bdb/ef01/7044/4b2a 步骤4
步骤 5 · 配置企业微信侧边栏（本项目核心）
① 从纷享后台「SCRM 配置向导」获取各侧边栏 URL（或联系工作人员）→ ② 企微后台「客户与上下游-聊天工具-聊天工具栏管理」→ 配置应用页面 → 选应用 → 填页面名称 + 页面内容（应用主页 或 自定义 URL）→ ③ 拖动调整侧边栏顺序。证据：/86b2/9bdb/ef01/7044/4b2a 步骤5
步骤 6 · 返回 CRM 后台关联企业微信
后台设置-集成平台管理-连接器-企业微信 → 去授权（企微管理员扫码）→ 账号绑定（CRM 员工账号 ↔ 企微员工账号一对一）。企微版 CRM 自动同步组织架构。证据：/86b2/9bdb/ef01/7044/4b2a 步骤6

P4 · 聊天工具栏 5 项能力配置细则 —— 一个侧边栏能挂什么

纷享SCRM 的聊天工具栏提供 5 项能力（/86b2/9bdb/9803/fdf4），展示了"一个应用可挂多个侧边栏页面、每页不同内容类型"的完整模式。这是本项目订单助手侧边栏页面划分的直接参照。

侧边栏能力承载应用页面内容类型URL 来源典型用途
CRM 主页纷享销客CRM应用主页无需（应用默认主页）客户总览/工作台，进入即看
CRM 详情纷享销客CRM自定义纷享后台 SCRM 配置向导复制链接当前会话客户的详情（订单/线索/客户关联）
营销助手纷享营销助手（代开发）应用主页无需（代开发应用主页）打标签/推物料/营销任务/客户动态
话术库纷享销客CRM自定义纷享后台复制链接销售话术检索/快捷发送
服务工单纷享销客CRM自定义纷享后台复制链接售后工单处理
模式提炼（对本项目至关重要）：「应用主页」适合无需会话上下文的入口（工作台）；「自定义 URL」适合会话上下文页面（详情类）——自定义 URL 页面可携带会话上下文参数，正是本项目「群上下文 → 客户订单列表/订单详情」的实现方式，与 docs/ui/wecom_tech_survey.html 的 ww.getCurExternalChat 群上下文方案一致。

P5 · 企微侧扩展能力 —— 数据打通 / 会话存档 / 消息推送

5.1 企微好友数据同步（客户数据打通）

纷享「企微好友数据同步设置」（/86b2/9bdb/5015/cac7）揭示企微好友 → CRM 业务对象的自动同步机制，与订单系统的客户主数据打通直接相关：

  • 同步对象：企微好友 → 销售线索 / 客户 / 联系人（三页签分别开启）
  • 同步时机：直接同步（添加好友即同步）或 满足条件同步（条件配置器/APL 函数）
  • 查重处理：继续创建 / 阻断 / 绑定已有（默认客户、联系人按电话查重并绑定已有）
  • 关联关系：同步后企微好友与业务对象建立关联；侧边栏「CRM 详情」可人工关联/新建/导入
  • 范围：仅同步「开启开关后新增」的好友（存量不回补）
映射：订单系统客户主数据 = 企微好友 + 公司信息；可在客户「添加好友」事件上触发客户建档/查重绑定（对应本项目 Customer 实体的 OWNS 关系建立）。

5.2 企业微信会话存档（履约审计/纠纷取证）

纷享会话存档基于企微「数据与智能专区」能力（/86b2/9bdb/6e0a/5dc6），三段式配置：

① 代开发应用启用「数据与智能专区」
企微后台 → 应用管理 → 纷享销客代开发应用 → 授权信息 → 数据与智能专区 → 去授权 → 前往启用。前置：购买 SCRM 会话存档与质检。
② 上传《企业微信会话内容使用授权函》
企微后台 → 安全与管理 → 管理工具 → 数据与智能专区 → 企业会话内容 → 前往配置 → 启用 → 上传授权函。
③ CRM 后台布局配置
新企业直接可用；老企业需在预设对象管理中将「企微会话存档」组件拖出布局。会话内容同步至 CRM「企业微信会话存档」对象（列表/分屏/三栏三视图）。
注意：会话存档需「代开发应用」形态（企业自建应用无法直接启用数据与智能专区）；且需购买付费能力 + 上传授权函。订单履约场景中，若需对"群内口头下单"做审计留痕，这是唯一合规路径。

5.3 企微端消息提醒（审批/待办触达）

纷享「企微客户端消息提醒」（/86b2/ed79/bcd4/699a/86f8）确认：企微互通后，CRM 的待办/审批/业务流程消息直达企微消息列：

接收入口消息类型订单履约对应
企微-消息列-应用通知待处理审批/业务流程/阶段进程/线索/工单/审批消息/工作流消息订单审批待办、闸门通知（审价/到账/备货/发货/开票）
企微-对话框侧边栏-营销助手推广任务/定向邀约/标签建群（营销可选）
企微-消息列-群发助手客户群发任务（营销可选，如发货通知群发）

6.3 落地步骤建议（对照纷享 6 步）

ROLLOUT

订单履约系统企微集成上线路线

阶段一（P0）：① 企微后台创建「订单助手」自建应用 → ② 设置可见范围（销售/商务/仓管/财务等标签）→ ③ 开启客户联系权限（范围一致）→ ④ 后端实现「侧边栏 URL 生成器」产出各页面 URL → ⑤ 聊天工具栏管理配置应用页面（订单工作台=应用主页；订单详情/下单/发货=自定义 URL）→ ⑥ 后端实现 OAuth 双票据 + 重认证 + 上下文路由 → ⑦ 应用消息推送接入审批流 阶段二（P1）：话术库/发货页/客户数据同步 阶段三（P2/P3）：会话存档（若需审计）→ 多组织/继承（预留）

关键差异提示：纷享作为服务商走「代开发应用」；本项目作为企业自研，走「自建应用」形态即可获得聊天工具栏/工作台/消息推送全部挂载点——只有会话存档需额外申请数据与智能专区。

P7 · 风险、边界与结论

7.1 边界与注意

  • 侧边栏仅外部会话可见：聊天工具栏只出现在与客户私聊/客户群会话，企业内部聊天不显示（证据）；内部协作需走工作台入口。
  • 可见范围与权限范围一致：聊天工具栏使用范围推荐与应用可见范围一致，否则出现"应用可见但工具栏不显示"。
  • 代开发应用授权不可省：未确认授权会导致部分数据无法同步。
  • 会话存档门槛高：需付费购买 + 代开发形态 + 授权函上传，非必需不要上。
  • 好友同步仅增量：开启后的新增好友才同步，存量需人工/其他路径。
  • 1+N 不可逆：多组织业务一旦开启无法关闭，单租户阶段勿开。

7.2 结论

纷享销客的企微整合实证表明：「企微自建应用 + 聊天工具栏自定义 URL + 应用消息推送」三件套即可完整支撑订单履约场景——侧边栏承载会话上下文操作（查订单/下单/审批），工作台承载无会话操作（全量待办），消息推送承载触达（审批/状态通知）。本项目 docs/ui/wecom_tech_survey.html 与 spec/ui/wecom-sidebar 的设计与此完全同构，可直接按本调研的配置路径落地。
