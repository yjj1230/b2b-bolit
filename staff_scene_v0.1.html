1 · 配置注入（测试/生产不同）

原则：域名备案已完成，但测试环境与生产环境的 corp_id / agent_id / secret / token / AESKey / domain 不同，必须通过以下配置注入，代码中不再写死。

1.1 租户配置模板

config/wecom-tenant.test.example.json   # 测试环境模板
config/wecom-tenant.prod.example.json   # 生产环境模板
config/wecom-tenant.example.json        # 通用示例

现场创建真实文件（不入库密文）：config/wecom-tenant.test.json、config/wecom-tenant.prod.json，字段必须包含：

{
  "tenant_id": "chang-an",
  "corp_id": "真实企业 ID",
  "domain": "已备案可信域名（测试/生产不同）",
  "app": {
    "agent_id": 1000002,
    "secret": "应用 secret",
    "token": "回调 token",
    "encoding_aes_key": "43 位 base64 AESKey"
  },
  "archive": { "enabled": false, "publickey_ver": 1, "private_keys": [], "secret": "" }
}

1.2 环境变量注入

# 测试环境
B2B_WECOM_PROVIDER=official
B2B_WECOM_TENANT_CFG_FILE=./config/wecom-tenant.test.json
B2B_WECOM_CONTEXT_SECRET=test-context-secret-xxx

# 生产环境
B2B_WECOM_PROVIDER=official
B2B_WECOM_TENANT_CFG_FILE=./config/wecom-tenant.prod.json
B2B_WECOM_CONTEXT_SECRET=prod-context-secret-yyy

docker-compose.yml 已支持：api / worker / wecom 三个服务统一挂载租户 JSON 到 /etc/b2b/wecom-tenant.json，并由 B2B_WECOM_TENANT_CFG 注入。

1.3 群上下文绑定注入（数据库）

INSERT INTO wecom_context_bindings (tenant_id, external_user_id, group_id, binding)
VALUES ('chang-an', '', '真实客户群 chat_id',
        '{"kind":"customer_group","customer_id":"真实客户 record_id","owner_user_id":"归属销售企微 userid","owner_name":"张销售"}');

仓库群：{"kind":"warehouse_group","warehouse_id":"wh-xxx"}。绑定缺失时 H5 会明确提示「未识别客户群，功能受限」。

3 · PC 端销售助理闭环

PC-1 飞书 OAuth：点击授权 → 旧系统回调 → 身份回填（token 缓存 2h）
PC-2 工作台代下单 XSZL1：先选归属销售 → 客户 → 预填 → 提交成功，提示 flow_id/instance_id
PC-3 客户群入口代下单 XSZL2：/assistant/?chat_id=… 打开 → 客户/归属销售锁定（readonly）→ 提交
PC-4 我的订单列表显示状态/当前节点；点击「查看详情」展示订单详情
PC-5 详情跳转旧系统 /flows/:flow_id 可打开（四环节快照 + 事件时间线）
PC-6 旧系统飞书审批中心出现待办；主管/董事长按 V01 profile 收到待办
PC-7 同键重复提交幂等；token 失效后重授权可继续

4 · 企微端销售助理闭环（V-C/V-D/V-E）

V-C 出站模板卡：测试成员收到 template_card；点击「通过/驳回」→ cmd/wecom 验签 → HTTP Signal 成功；已决任务幂等 409 回执
V-D 聊天工具栏/工作台打开 H5：ww.register + wx.agentConfig 双签名成功；OAuth 静默授权完成；顶部显示身份
V-D-2 客户群入口：H5 自动解析群上下文，客户与归属销售带出并锁定；未绑定群显示黄色提示
V-D-3 工作台入口：先选归属销售，再人工选客户；客户范围正确
V-E 守门员：点「发给客户」→ 守门员确认 → 客户群收到消息（未发货订单卡片不含金额）
V-E-2 若 appchat/send 对外部客户群不可达：回退为「销售人工转发」或切换 externalcontact 群发接口；回退决策与证据写入验收单
V-F 仓库群回单：发回单照片 → 机器人抓取/识别 → 匹配订单 → 追加凭证版本（只追加不覆盖）

6 · 已知风险与现场处理

R-1 旧系统 T-01 未改：v0.1 幂等键前缀识别 + 自动确认 + V01 profile 注入。必须先在 tripartite-approval 仓库完成并独立测试，否则订单会卡「信息确认」。

R-3 会话存档：官方 decryptMessage 基线是占位实现；v0.1 自动下单不做，不影响销售助理人工下单。若 V-F 依赖真实消息回调图片 URL，需现场确认回调字段。

R-4 角色映射：官方 userid 当前默认 OP（销售助理语义）；非助理角色接入需扩展 demoRoleOf 或角色映射配置。

R-5 备案域名：已就绪；仍需确认 JS-SDK 域名白名单与 B2B_WECOM_TENANT_CFG.domain 完全一致（含端口/子域）。
