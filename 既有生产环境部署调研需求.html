0 · 本指南使用说明与红线

0.1 红线：不采集、不回传、不落盘的内容

本指南只采集部署与运行状态，不采集任何秘密值。以下内容禁止出现在任何截图、命令输出、表格、聊天记录、报告中：

禁止采集项正确做法
飞书应用 app_secret只确认「已配置、未过期、最后一次轮换日期」
旧系统 CREATE_ORDER_AUTH_SECRET / FEISHU_ACTION_CALLBACK_TOKEN只确认「配置项存在、与环境变量/配置文件一致、是否即将过期」
企微/飞书机器桥接 secret（如 WECOM_TEST_BRIDGE_SECRET / PRODUCTION_ORDER_BRIDGE_SECRET）只确认「存在、长度符合预期、未硬编码在代码仓库」
数据库密码 / pgAPI X-API-Key / 各类 token / view_token / approver_token只确认「已配置、鉴权生效、未明文出现在日志/截图」
完整 open_id / 手机号 / 身份证等人员明文信息只记录「前 4 后 4 + 脱敏指纹」；数量、一致性、归属角色
客户合同、金额明细、商品底价等业务敏感内容只统计计数、文件大小、状态分布，不回传明细

一句话：凡是能用来通过身份校验、解密、冒签的字符串，一律只确认「在不在、对不对得上、有没有过期、最后一次轮换是什么时候」。

0.2 本指南的目标

按三次发布的时间线，把生产现场还原为可写进分析文档的一手证据，最终达到：

  • 部署可还原：每套系统的进程、端口、路径、版本、启动方式、服务依赖可画成拓扑图。
  • 数据可对账：旧系统 JSONL、飞书多维表、pgAPI PG、新系统 PG 各数据面的计数与时间戳可互相核对。
  • 发布可决策：第 1/2/3 次发布前，每个 P0 项都有「生产现场已确认/未确认」的状态。
  • 风险可定位：双通道并发、存量待办、事件链完整性、附件归属等风险点都能对应到生产证据。
  • 切换可演练：第 3 次发布的全量迁移、对账、冻结、切换、回滚各步骤，都有现场可执行、可验收的证据项。

2 · 通用取证规范与证据分级

2.1 证据编号规则

每条证据使用统一编号：EVID-{发布阶段}-{系统}-{主题}-{序号}，例如：

  • EVID-R1-OLD-拓扑-01：第 1 次取证，旧系统拓扑第 1 条。
  • EVID-R2-NEW-待办-03：第 2 次取证，新系统待办视图第 3 条。
  • EVID-R3-DATA-事件链-02：第 3 次取证，事件链完整性第 2 条。
  • EVID-BASE-OLD-数据-01：跨发布基线，旧系统数据面第 1 条。

2.2 证据采集方法（只读优先）

方法适用对象要求
截图管理后台、配置页、看板必须包含：系统时间、URL/路径、关键状态；截图后立即编号
命令输出进程、端口、文件计数、服务状态只读命令；输出粘贴为文本或截图；禁止回显密码/密钥
配置核对配置文件、环境变量、角色映射只记录键名与「是否一致/是否过期/是否脱敏」，不记录值
文件清单JSONL、附件、迁移文件记录：绝对路径、文件名、行数、字节数、最早/最晚时间戳、MD5/SHA256 可选
接口探测健康检查、只读 API使用 GET/健康检查；不传任何 token；如必须鉴权，使用现场已配置环境且不回显 Header

2.3 证据可信度分级

等级含义要求
L1 · 可复核能由第二人重复执行并得到相同结果附只读命令 + 输出 + 执行时间 + 执行人
L2 · 可追溯来自系统界面/日志/文件，有明确来源附截图/路径/行号/时间戳
L3 · 访谈来自业务/运维口述必须记录「谁说的、何时说的、原话摘要」，并在报告中标注为待 L1/L2 复核
L0 · 无证据无法取证明确标注「未取证」，不得用假设填补

附录 B · 敏感信息红线与脱敏规范

B.1 禁止采集清单（再次强调）

下列内容不采集、不截图、不回传：

  • 飞书 app_secret、企微 secret、各类 app_secret。
  • 旧系统 CREATE_ORDER_AUTH_SECRET、FEISHU_ACTION_CALLBACK_TOKEN、WECOM_TEST_BRIDGE_SECRET、PRODUCTION_ORDER_BRIDGE_SECRET。
  • 数据库密码、pgAPI X-API-Key、对象存储 AK/SK、TLS 私钥、加密 AES key。
  • 各类 token（view_token、approver_token、submitter_token、OAuth token、create-order token）。
  • 完整 open_id、user_id（记录前 4 后 4 + sha256 前 8 位指纹）。
  • 客户/订单/金额/底价等业务明细（只统计计数与分布）。

B.2 脱敏方法

信息类型允许记录形式
密钥/密码/令牌只记录：键名、是否存在、是否过期、最近轮换日期、长度范围；值一律以 *** 代替
open_id / user_idou_2967****d38 + sha256(open_id)[:8]
公网 IP / 域名可记录（部署拓扑需要）
端口 / 路径 / 版本号可记录
业务明细只记录 COUNT / SUM / MIN / MAX / 状态分布；不回传行级明细
配置项值（非密钥）可记录，例如：角色 key、节点 ID、表名、字段名、文件路径

B.3 一句话总结

取证目标：用最少的敏感信息，还原最完整的生产现场。凡是与「部署、版本、路径、端口、计数、状态、时间、配置键名」相关的，尽量采集；凡是与「秘密值、令牌、密码、完整个人标识、业务明细」相关的，只确认状态、不采集值。
